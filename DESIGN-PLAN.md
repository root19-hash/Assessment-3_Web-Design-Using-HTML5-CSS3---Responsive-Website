# Assessment 3 Visual Plan

## Direction

Create a calm, editorial library service interface: warm paper surfaces, terracotta action accents, deep maroon navigation, and restrained image treatment. The visual tone should feel reliable and academic without looking institutional or generic.

## Page hierarchy

- Shared site header: clear service identity and short supporting message.
- Shared navigation: one predictable row on larger screens and a stacked touch-friendly list on small screens.
- Main content: constrained reading width with strong section headings and deliberate whitespace.
- Supporting content: cards and panels for comparison, booking help, and quick updates.
- Footer: quiet closure with assessment ownership information.

## Layout plan

- Flexbox handles the one-dimensional navigation and compact action groups.
- Grid handles hero splits, service comparisons, contact columns, and gallery media.
- The layout changes structure at mobile, tablet, and desktop widths rather than only shrinking text.

## Quality goals

- Keep every page visually related through shared tokens and components.
- Keep content readable with strong contrast, visible keyboard focus, and descriptive media text.
- Keep CSS organized by reset, tokens, global elements, components, layout utilities, and responsive overrides.
- Test at approximately 375px, 768px, and 1200px before the final publication stage.
